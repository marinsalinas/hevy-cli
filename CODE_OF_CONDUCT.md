# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. The canonical text lives at that URL; by participating in this project's issue tracker, pull requests, or discussions, you agree to uphold it.

## Scope

Applies to all project spaces: the GitHub repository, issues, pull requests, discussions, and any other forum where individuals are representing the project.

## Reporting

To report a concern, email the maintainer at **marinssalinas@gmail.com** with the subject line `[hevy-cli CoC]`. Reports are handled privately. If the concern involves the maintainer directly, refer to the enforcement escalation paths described in the Contributor Covenant.

All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter.
